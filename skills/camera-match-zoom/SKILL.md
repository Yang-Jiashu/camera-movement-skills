# 匹配变焦

先找到两个镜头能承接注意力的锚点，再用快速变焦阶段完成场景切换，最后恢复清楚的观察构图。

## 输入与锚点

- 需要两个视频，分别指定选段起点、输出画幅、整段时长与切换中心。
- 选择可辨认的环口、门洞、窗框、人物或其他形状关系；锚点最好具有相近的朝向和视觉重心。
- 从实际首帧读取A、B各自的位置，不机械使用画面正中，也不把A坐标复制给不同构图的B。
- 透视、轮廓差异过大时，先换片段或缩小期望。变焦匹配是剪辑衔接，不会自动重建两个场景之间的空间。

## 参数与执行

| 参数 | 语义 |
| --- | --- |
| `--anchor-a x y` / `--anchor-b x y` | 两输入各自的归一化锚点，范围0–1 |
| `--base-zoom` | 观察段的取景倍率，应保留主体与必要环境 |
| `--peak-zoom` | 快速过渡的最大倍率，按素材细节和切换目的选择 |
| `--cut-at` / `--transition` | 输出时间线上的切换中心与衔接区间 |

例：连接两个偏心构图，锚点必须按实际素材修改：

```bash
python3 scripts/apply_camera_motion.py match-zoom --input first.mp4 --input-b second.mp4 --output match.mp4 --duration 4 --anchor-a 0.35 0.4 --anchor-b 0.65 0.45 --base-zoom 1.05 --peak-zoom 3 --cut-at 2 --transition 0.25
```

先看 `match-zoom --help` 再设置源起点、尺寸与FFmpeg。两输入按输出画幅等比裁切；如裁切损失关键锚点，先重构图或调整输出画幅。

## 幅度与清晰度

短暂高倍率放大可以作为速度感的一部分，但不要把过渡中的放大采样标成恢复了真实细节。观察段与高速过渡分别检查清晰度。

最模糊处经过切点，之后及时恢复可读画面。避免持续模糊、非意图白闪或把主体拉伸成相似形状。场景曝光差异可以保留为昼夜变化，不用长时间形变伪装成真实连续运动。

默认无声，另行组织音效、音乐和原声的衔接；双视频不提供假同步原声。HDR先显式转SDR。

## 验收与交付

正常播放整个A→B，观察注意力是否落在预期位置。慢看快速推近、切换与拉出段，检查锚点漂移、空边、过曝、几何拉伸及落点模糊。

交付记录两个源选段、各自锚点、峰值与观察倍率、切换区间及实际中心修正。称“匹配变焦/数字zoom cut”，不称真实机位推拉配合光学反向变焦的dolly zoom。

## 运行入口

视频入口按CFR帧索引处理，VFR不会自动检测；精确时序或原声同步前核查帧率，必要时先规范为明确的CFR。

本技能共用整库运行时。仓库根目录用 `scripts/apply_camera_motion.py match-zoom`；安装后本技能的 `scripts/run.py` 已固定子命令，参数相同。先读 `--help`；仅复制技能目录不会自动安装共享代码。
