# 有限视差的CV处理设计

低层入口消费前景、背景和alpha做刚性两层运动；高层camera_pipeline parallax从ROI/alpha执行GrabCut分层、Telea/NS有限补洞与运动预算，再渲染。不依赖单目深度网络，不做稠密场景重建或真实相机轨迹求解。

## 1. 输入契约

- 两张已配准的8位SDR RGB图和前景等尺寸alpha；白为前景、黑为后景。
- 指定各层相对覆盖倍率、起止位移、共同归一化锚点、时长和输出尺寸。
- 图层的前后关系与实际遮挡一致；背景含足够的边缘支持及可接受的遮挡补洞。高层pipeline可从单张原图与明确ROI/种子准备这些资产，并保留QA与实际允许的运动。

## 2. 分层与深度的设计流程

1. 先按叙事目的选前景/主体/远景，而非机械把深度图等分成多个区间。
2. 可选人工mask、传统GrabCut或外部分割模型；需要深度时，可选单目深度模型辅助排序，但应在建筑、细枝、反射和透明区域人工复核。
3. 单目深度一般只作为相对层次线索，不把数值当作可靠距离；不要直接按每像素深度无约束扭曲刚性建筑。
4. 若确有多视图，可另行用特征匹配、相机位姿与重建流程获得更多实际空间；当前两层命令并未实现这些能力。

同库预处理技能存在时可按其实际帮助准备mask；缺失时人工图层与本页流程即可开始。模型推理、权重下载与API能力需要实际工具支持，不能仅凭本技能宣称已完成。

## 3. 运动前的支持区设计

- 由最大层间位移反推需要露出的背景范围，先检查最坏位置再动画。
- 对水面、天空等小孔可考虑传统修补；大面积未知背景应补充参考或明确生成，并说明来源。
- 让近处层相对位移更明显可以产生视差；但符号、比例与锚点应由本镜头决定，不固定“所有前景都右移”。
- 地面接触、栏杆连接、人物脚部等处应选择连贯分层，避免漂浮卡片和断裂接缝。

## 4. 已有合成步骤

1. 分别计算前景与背景的覆盖比例，再应用显式倍率与归一化输出位移。
2. 以共同锚点构造刚性尺度和平移变换，不根据深度图做逐像素重投影。
3. 对背景完整采样支持区检查，越界默认停止；显式clamp只调整位移，不能修复背景太小导致的覆盖不足。
4. 使用同一前景变换采样RGB和alpha，再与背景混合。前景透明之外的区域由真实或已记录的补洞背景提供。
5. 当前命令只有两层、单段插值路径；多层或曲线弧移需另行组合或扩展实现，不把两层直线位移称作完整orbit。

## 5. 失败恢复

- 前景细边拉丝/光晕：检查alpha配准、边缘颜色污染和缩放插值；缩小幅度或换更适合分层的主体。
- 背景补洞暴露：减少最大位移，扩充实际背景素材，或修改构图；延长模糊不等于恢复几何。
- 看起来没有纵深：检查近远层是否确有相对运动及可辨认结构，不单纯增加整幅缩放。
- 用户要求准确三维绕拍：转到实拍、多视图重建或明确的3D场景流程，而非继续扩大2.5D幅度。

## 6. 验收与指标

**当前报告已有**：前后景倍率范围、背景最小采样余量、合成声明与输出解码/帧数/fps/尺寸。

**需另行测量/观看**：层间相对位移、前景刚性、地面接触连续性、alpha边缘稳定、补洞可见区域及异常重复结构。测量时区分层运动与相机运动，像素位移并不等于真实相机移动距离。

正常播放和边缘抽查均需完成，阈值随主体尺度、运动幅度与用途校准。交付为有限2.5D视差或合成弧移，不是完整场景三维重建。
