# 已有照片与视频：后期运镜

适用：用现成素材设计或执行数字重构图、拼接画布移动、有限视差及相关衔接。先按素材能支持的空间变化选手法，再决定动作幅度。

## 判断素材能支持什么

- 看起始、中段、结尾与完整运动片段，辨认原片的机位移动、镜头转向、光学变焦和主体运动；原片已有清晰运动时，先考虑保留或截取，不自动叠加反向移动。
- 读取旋转与显示方向、显示尺寸、像素宽高比、帧率和输出画幅。所有坐标统一到校正后的显示画面；“竖屏 4K”裁成横屏不等于仍有 4K 横屏的细节余量。
- 确认主体在整个片段里的位置与遮挡变化，并找出地平线、建筑边缘、人物肢体等不能被意外裁断的参照。
- 若同时稳像、校正镜头畸变、旋转或改画幅，使用这些处理后的有效画面计算余量。它们共同消耗裁切空间，不能分别按原图尺寸承诺放大幅度。

## 选用方式与边界

| 方式 | 素材条件与合适用途 | 不能据此声称的效果 |
| --- | --- | --- |
| 二维裁切移动 / Ken Burns | 画幅有余量；通过缓移或推近把注意力交给实际细节 | 新视点、真实视差、绕到物体侧面 |
| 多图配准与拼接后移动 | 同场景有可靠重叠；接缝与曝光能协调；在可用画布内揭示更多已拍到的区域 | 单一平面拼接不等于三维重建或真实横向平移 |
| 深度分层视差 | 前中后景可分，遮挡边界可修，运动小到不会露出大面积未知背景 | 准确几何、完整物体背面、无损大幅环绕 |
| 原始移动视频 + 动态缩放 | 原片包含相机接近/远离主体的透视变化，可跟踪主体尺寸并反向调整缩放 | 任意静止片段经缩放即可获得真实 dolly zoom |
| 局部光流或形变 | 有可支持的帧间变化，或用户明确要合成局部动画 | 光流插帧不能证明照片里的车、水、人确实发生过该运动 |

多图若含明显近远景视差或独立运动物体，先检查接缝随裁切移动是否暴露重影、断线或重复主体。单应性不适合解释任意跨视点的三维场景；匹配不可靠时用独立镜头、分区处理或较小移动。

深度分层中，新露出的遮挡区没有原始像素时，需要修补或生成，并如实说明。建筑刚性边缘、细枝、头发、透明物和反射面容易显露分层问题；缩小幅度通常比继续拉伸背景更合适。

## 二维裁切的可验证规格

以下公式仅用于已校正方向、方形像素、无额外旋转的矩形画布。设有效源图为 `Ws × Hs`，输出为 `Wo × Ho`，输出宽高比 `r = Wo / Ho`。

```text
Bw = min(Ws, Hs × r)      # 可容纳的最大同画幅裁切宽度
Bh = Bw / r
w(t) = Bw / z(t)          # z ≥ 1；z 增大表示数字推近
h(t) = Bh / z(t)
w(t)/2 ≤ cx(t) ≤ Ws - w(t)/2
h(t)/2 ≤ cy(t) ≤ Hs - h(t)/2
z(t) ≤ min(Bw/Wo, Bh/Ho)  # 希望不放大采样时的上限
```

`cx, cy` 是裁切窗口在源图中的中心。裁切窗口向右移动会让画面内景物向左移，写镜头表时明确说的是窗口方向、摄像机方向还是主体在画面里的方向。

对主体关键点 `px(t), py(t)`，可以直接检验其输出归一化位置：

```text
u(t) = (px(t) - cx(t)) / w(t) + 0.5
v(t) = (py(t) - cy(t)) / h(t) + 0.5
```

根据构图需要给 `u, v` 留边，检查整个主体包围框和预测运动，不能只让跟踪中心留在画内。若比例上限小于 1，满幅输出已需要放大，先说明画质代价或调整输出选择。

例：有效源图 `3840 × 2160` 输出 `1920 × 1080`，同画幅裁切的 `z` 在无放大采样条件下最高为 2。若先稳像或旋转，此上限需重算，不能继续直接套用原值。

存在稳像、镜头校正、旋转或拼接的非矩形有效区域时，上述矩形边界不够。将输出窗口经变换逆映射回源图，检查整块采样足迹是否位于该帧有效区域内；把这项检查与主体留边放在同一套几何变换中。

## 运动与衔接

- 以“从哪里看到哪里”为规格，说明起止构图、移动时长、窗口/机位方向、速度变化与主体位置。轻柔揭示通常适合平滑起停；与前后镜头匹配的持续行进不必每镜重新缓起缓停。
- 尊重原片主体的行进方向、视线及相邻镜头空间关系。先区分有意反向或反打与意外跳向；不要只为统一运动方向就镜像文字、地标或人物动作。
- 避免把每张照片都做等幅缩放。选择确实能揭示信息的照片移动，并用固定镜头、原片自然运动与不同景别提供节奏变化。
- 甩镜、遮挡衔接和变速需有具体连接动机；一段模糊不能自动修复前后空间关系。合成遮挡转场要检查遮挡边界随时间是否贴合，而不只检查切点。

## 验证与交付措辞

按正常速度播放运动片段与前后连接，必要时慢放检查；抽看起止帧无法发现中途出界、跟踪跳动、接缝漂移或加减速突变。对重要几何约束可逐帧检查，发现问题再缩小幅度、改变路径或更换方法。

交付用“原片机位移动”“二维数字推近”“拼接画布上的数字摇移”“深度分层合成视差”等准确措辞。若没有实际检查素材或渲染结果，把动作与幅度标成设计建议，不写成已验证的成片效果。
