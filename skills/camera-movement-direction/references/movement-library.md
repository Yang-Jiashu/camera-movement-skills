# 运镜库：动作、用途与误用

按动作而非流行度排序；这些是常用的电影和视频语言，不是热度榜。下面“用途”是设计起点，具体情绪取决于剧情、时长、声音与构图。

## 基本动作与常见组合

| 中文 / 英文 | 实际发生什么 | 适用判断与易错点 |
| --- | --- | --- |
| 推近 / Dolly in, Push-in | 相机朝主体接近 | 强调反应或逼近；近远景关系随视点改变。推近不等于 zoom in |
| 拉远 / Dolly out, Pull-back | 相机远离主体 | 让细节落入环境；终点要有可揭示的空间 |
| 横摇 / Pan | 机位基本固定，镜头向左或右转 | 浏览或转移注意；相机并未沿场景横向平移 |
| 俯仰摇 / Tilt | 机位基本固定，镜头向上或下转 | 沿建筑或人物逐步揭示；不等于相机升降 |
| 横移 / Truck, Lateral tracking | 机位沿左右方向移动 | 近远景产生相对位移；同时转向看主体要额外说明 |
| 升降 / Pedestal | 机位竖直升降，朝向可以保持 | 越过前景或换观察高度；只有镜头上仰仍是 tilt |
| 摇臂 / Crane, Jib | 机械臂带来升降或弧线路径 | 大幅空间揭示；是设备及其路径族，不保证纯竖直 |
| 跟随 / Tracking, Follow, Lead | 机位随主体移动，可在侧后方或前方领拍 | 跟随描述相对关系；应补充方向、距离和主体落点 |
| 环绕、弧线 / Orbit, Arc | 机位围绕主体运动并维持取景 | 强调体积或关系；注明弧段、观察方向和终点，orbit 不必自动理解成整整一圈 |
| 变焦 / Zoom in, Zoom out | 机位固定时改变焦距与视场 | 同一视点下改变主体占比，不凭空产生新的遮挡关系；数字裁切是后期模拟 |
| 希区柯克变焦 / Dolly zoom, Vertigo effect | 机位推或拉，同时反向变焦 | 协调两者使主体尺寸近似不变、背景关系改变；必须有深度层次 |
| 甩镜 / Whip pan | 很快地横摇，通常伴随运动模糊 | 突然转移注意或连接段落；先设计甩动前后的落点 |
| 急变焦 / Crash zoom | 快速改变焦距 | 突然强调细节；与甩镜不是同一动作 |
| 滚转 / Roll | 相机绕镜头光轴旋转 | 地平线随时间倾转；静止斜构图属于 Dutch angle |
| 遮挡揭示 / Reveal through foreground | 以移、升或摇让主体从前景后露出 | “揭示”是信息组织方式；写明遮挡物、移动路线和露出什么 |
| 穿行 / Fly-through, Walk-through | 机位沿门洞、走廊等可通行路径进入空间 | 需连续可见空间与合理尺度；设备可为人持、稳定器、无人机或虚拟相机 |
| 航拍 / Aerial, Drone movement | 高处或飞行机位配合推进、升降、环绕等 | 航拍说明平台/位置，继续补充实际轨迹；高机位也能静止 |
| 手持 / Handheld | 人手操持，通常保留一定微动 | 现场感、紧张或亲近；不等于必须大幅乱抖 |
| 稳定器跟拍 / Gimbal, Steadicam | 稳定系统配合行走与转向 | 描述设备/运动质感，仍需具体轨迹；两种稳定系统不必混称 |
| 固定镜头 / Locked-off, Static | 相机保持静止 | 让人物、车流、水等构成运动；可以作为运动段落之间的停顿 |

## 常被一起讨论，但不是新的机位运动

- **Rack focus / 移焦**：清晰区域从前景转向后景或另一主体，改变注意力。
- **POV / 第一人称视角**：叙事视点，既可静止也可运动；FPV 常指第一视角飞行及其影像风格，不是某一条固定轨迹。
- **一镜到底 / One take**：镜头连续性的组织方式，可以组合多个运动。隐藏切点形成的表观连续镜头可称“伪一镜到底”，不要误报为真实单次拍摄。
- **Speed ramp / 速度渐变**：时间重映射；**延时/移动延时**是采样及播放时间方式；**子弹时间**通常涉及多视点获取或重建，不能作为普通单机横移承诺。
- **Ken Burns**：对静态图像做平移和缩放的呈现方式，属于二维重构图。
- **遮挡转场、动作匹配切换、J/L cut**：镜头连接手法；遮挡揭示可以在单镜头内发生，遮挡转场则涉及连接两段画面。
