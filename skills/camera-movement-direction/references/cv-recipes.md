# 按镜头组合视觉处理

使用时只展开当前素材对应的配方。基础prepare_motion与apply_camera_motion、资产motion_masks/motion_layers/motion_match和组合camera_pipeline均是现成入口；“外部”步骤需要可用工具与实际执行。下列不是一键配置，也不预设全部模型可用。

## A. 手持街景：轻稳像 → 推近/滚转

1. 看起止构图，保留原片行进方向；将切点或遮挡剧变处分段。
2. 在建筑/地面选择背景ROI，用 `analyze` 查LK与RANSAC支持；玻璃、树叶、水流不作唯一依据。
3. 若有妨碍阅读的短周期抖动，`stabilize`做轻度修正；原片顺滑则跳过。
4. 读取新片尺寸，规划reframe/roll；把稳像损失与旋转最坏角度裁切一起算，不能两次都以完整原片余量承诺。
5. 先导出动作最大处与边界风险处的短样，再导整段；检查回正、人物完整性与建筑是否扭动。
6. 交付处理顺序、稳像报告、效果报告；稳像为静音中间片，声音另对齐。

**退路**：裁切过多则降低强度/角度、缩短镜头或换素材；全局模型不成立时不强行“稳住”。

## B. 人物/车辆：初始化 → 跟随取景 → 失跟分段

1. 在最终工作片的选段首帧明确主体ROI，避免把大块独立运动背景纳入。
2. 用现成 `subject-track` 的纹理LK+RANSAC跟踪；先设足够宽的crop，保留肢体与运动前方空间。
3. 看对象交叉、模糊、遮挡处；confidence仅是几何支持。需要身份再识别时使用外部检测/跟踪/重识别工具并人工核对，而非仅降阈值。
4. 平滑取景路径，观察延迟和追赶；快速动作不能因平滑而被裁出。
5. 完全遮挡/离框时按用户可接受区间hold或停止，重现后确认同一对象并重启下一段。
6. 输出跟踪报告与失效区间；若增加视频mask，保存object ID并检查与ROI一致。

**退路**：人工关键帧裁切或改为短镜头；当前CLI不导入外部语义轨迹，使用时需独立适配和验证。

## C. 建筑照片：静态分割 → 补背景 → 2.5D眩晕/视差

1. 用 `mask` 的矩形与正负种子提取刚性主体。检查尖角、栏杆、镂空，不把羽化当抠像正确。
2. 用motion_layers准备有限补洞背景并检查QA、运动预算；大运动优先真实无遮挡参考。camera_pipeline可将此步与渲染连接。
3. 可选外部深度只辅助判断层次；不用深度时同样可以手动两层设计。当前渲染入口不读取深度图。
4. 所有资产统一源坐标与尺寸；保留foreground色与alpha。预演最大相对位移，确保背景和前景不会穿帮。
5. `layered-vertigo`固定前景大小、改变后景尺度；`parallax`设计不同层的位移。一个镜头先用清楚主动作再考虑叠加。
6. 看前景边界光晕、补洞露馅、漂浮感及背景直线；注明有限2.5D，不能称真实环绕或实拍dolly zoom。

**退路**：减小运动、改普通reframe，或只展示已完成的手工资产，不声称自动深度重建。

## D. 门框/立柱：视频mask → 时序校对 → 遮挡转场

1. 找真实遮挡边缘跨过画面的区间，核对镜头A与B的运动方向及揭示内容。
2. 直边单次经过可用motion_masks的ROI初始化、双向稠密流和局部GrabCut产生物体与reveal序列；复杂曲线或交叉改用实际逐帧资产，不复制静态mask充数。
3. 校准mask源尺寸、开始时间、fps与编号。转场mask白色揭示B；分割前景白色需按实际遮挡关系转换/反相。
4. 沿边缘检查孔洞、运动模糊和逐帧跳变；有参考真值时可测边缘误差，无真值时用叠加播放人工修正。
5. `wipe --mask-dir`消费序列；检查第一/最后mask、完整帧覆盖与切点两侧的稳定落点。
6. 调色和声音配合揭示时机；无真实mask时可用几何擦除，但交付名称必须说明。

**退路**：选更短且遮挡清楚的区间、人工修mask或换转场；不靠过大羽化掩盖错时。

## E. 昼夜/地点：锚点确认 → 匹配变焦

1. 在两镜头中找相同或可匹配的刚性形状，如圆环、窗、建筑轮廓；流水、人群与反射不作唯一锚点。
2. 共同刚性纹理足够时用motion_match的SIFT双向ratio+RANSAC估计anchors，并查看内点图；无可靠对应时明确人工指定各自锚点。
3. 在拟切换帧比较锚点位置、大小、朝向与视觉重量，使用足够基础zoom给偏心锚点留余量。
4. `match-zoom`先推向A锚点，切换B，再拉出；不要假定手动两个中心点就是完整几何配准。
5. 光照差异决定保留昼夜感还是另做曝光匹配；高层CLI会估计锚点，但不自动匹配光照与色彩。
6. 正常速度看是否读到连接关系，再逐帧检查切点跳变/双影；锚点误差以输出像素或对角线比例记录。

**退路**：选更匹配的帧、人工微调、提高切点速度或改直接切；不强行将非平面强视差场景压成单应性。

## F. 列车/运动：动作落点 → 单调变速

1. 标出清楚动作与希望停留的观察区间，记录源fps及实际可用帧数。
2. 用 `speed-ramp` 的速度权重曲线分配时间；速度权重最终按源跨度和输出时长归一化，不能直接等同绝对倍速。
3. 检查输出到源的映射单调且不越界。慢段没有足够独立源帧时优先缩短输出或使用真实高帧率片段。
4. 如需外部光流插帧，双向流与遮挡处理另做，并检查列车边缘、栏杆、水幕的扭曲；本库未内置此模块。
5. 允许重复帧时显式设置并记录；检查节奏卡顿，不将其宣传为真实高帧率慢动作。
6. 根据新时间线做节拍、音效与必要的变声处理；原声不直接沿用。

**退路**：用短的清楚观察段承接快段，减少慢动作幅度；不要对所有帧开启不必要的光流。

## G. AI生成镜头：意图 → 外部生成 → 视觉验收

1. 明确主体、相机位移/转向/焦距、起止构图和预期新增可见内容，由AI提示词技能按当前目标平台能力表达。
2. 如需参考mask/depth/camera轨迹，先确认平台是否真正接受这些输入；本库不会自动把资产送给任意生成器。
3. 生成后用固定结构、主体身份和遮挡关系检查运动；背景flow方向与尺度变化可辅助区分数字缩放、转向和真实位移，但仅凭二维flow不能唯一恢复相机路径。
4. 需要定量检验时使用已安装诊断或外部工具，记录已执行分析，不能把提示词目标填成测量结果。
5. 失败优先简化同一镜头的复合动作、缩短时长或增加稳定参考；生成内容按实际路线标注。

**退路**：回到可控的实拍/二维/2.5D路线，或把不可执行部分交付为条件镜头规格。
