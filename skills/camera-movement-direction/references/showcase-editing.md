# 作品集与 GitHub 示例

用于用户明确要求抓眼、酷炫、作品集、showreel 或开源示例的场景。展示片可以把运动、节奏与转场作为主要观看目的，选用更鲜明的幅度和速度；不要自动沿用安静旅拍的克制强度。

## 做成看得见的能力

- 先挑能一眼辨认的三到六项效果，给每项一个完整起止动作。滚转应有明显轴向变化；甩镜应有清楚落点；变焦后应能看清主体。数量和时长按素材、任务调整，不硬凑清单。
- 快速运动前后留短暂停顿，让观众识别空间。用节拍、风切和低频落点组织动作，避免随机转场或持续模糊。
- 画面尽量占满屏幕，编号和简短技法名置于稳定区域。主片展示效果，README 或独立对比片承载实现说明。

## 可复用做法

| 效果 | 实现与关键条件 |
| --- | --- |
| 数字滚转 / Barrel roll | 绕光轴转一圈或指定角度；提前推近并留旋转余量。16:9 矩形绕中心旋转时，完整覆盖所需的最大倍率约 `sqrt(1+(16/9)^2)=2.04`，还需叠加偏心构图与稳像余量。高分辨率输入有助于保细节 |
| 甩镜转场 / Whip-pan transition | 用同方向快速位移与方向性运动模糊连接两段，最模糊时经过切点，终点恢复清楚画面。数字转场不能写成原片实际拍到的横摇 |
| 遮挡切换 / Occlusion wipe | 优先跟踪真实门框、立柱等边缘；核实掩码对应的源文件、分辨率、方向和起始帧。已处理版本不应未经对齐就复用旧掩码 |
| 匹配变焦 / Match zoom | 选择形状相似的视觉锚点，在快速推近阶段切换再拉出。短暂放大和模糊可用作转场，但把清晰观察段与高速过渡的采样质量分开说明 |
| 速度渐变 / Speed ramp | 改变真实运动的时间映射。对帧索引保持单调；减速优先利用高帧率原片，别把30fps缓存重复帧称为真实慢动作 |
| 分层眩晕 / Layered vertigo | 当真实前后移动不足时，可用刚性前景加反向缩放的背景演示2.5D眩晕效果。先检查遮挡补洞、轮廓与接缝；标签明确写“2.5D合成”，不称真实dolly zoom |

旋转的裁切边界应逐帧检查；高速动作前后都要确认回正和落点。分层构图先用首、中、末帧查轮廓，再看动态；前景主体可以保持刚性，同时保留有限的合成空间变化。

## 交付可复现示例

按用户范围准备主片、独立短片、轻量GIF/封面和复现代码。GitHub README 的图片与视频入口使用仓库内相对路径；不要嵌入个人电脑绝对路径或虚构远程链接。

将实际用到的规范化输入、掩码和参数纳入示例包，代码以参数定位资源；无需把全部原片、旧工程、系统字体或大型缓存塞进仓库。若配乐需要第三方署名，保留相应来源；原创合成声音写清实际制作方式。

验证渲染入口可在包内工作、所有链接存在、媒体能完整解码，以及播放时运动可辨认。用户没有指定发布目标时，先交付准备好的本地包；上传仓库需有明确目标，不能把“准备好”报告成“已发布”。
