# 遮挡合成的CV处理设计

低层wipe执行器消费mask序列；高层camera_pipeline wipe先执行ROI初始化、DIS/Farneback双向传播、局部GrabCut与直边揭示验证。它不运行语义模型，不支持将任意曲线物体自动当作直边转场。没有mask且用低层入口时为线性数字擦除。

## 1. 输入契约

- 两个SDR/CFR输入、选段起点、输出画幅、切换中心和过渡时长。
- 对应A的8位灰度mask：白色显示B，黑色保留A；mask宽高比需与A一致，并与A的实际取景、方向、源时刻对应。
- 提供命名模式、起始索引及mask原始fps。当前程序将过渡局部时间映射到索引，视频起点、过渡起点与mask索引不是同一种单位。

## 2. mask获取的算法选择

高层pipeline已封装刚性直边的准备；以下同时给出复杂情况的选择。低层wipe仅消费结果：

- 边界明确的立柱/门框：人工关键帧或颜色/梯度候选，加直线/多边形边界拟合；按实际遮挡方向传播。
- 有纹理的刚性遮挡物：在物体上跟踪角点，用LK与RANSAC估计局部相似/仿射运动，再用可见边缘修正，避免仅凭全局背景运动推断物体。
- 复杂轮廓：可用外部分割/视频mask传播工具，并检查身份、漏边、透明区域和遮挡交叉。自动分割模型不等于已获得正确alpha。
- 单次露出次序不明确：先做人工标注和短段验证；不要凭空外推未进入画面的实物轨迹。

如有 `camera-motion-prep` 的mask工具，先读已安装工具帮助核对其输入/输出；缺失时上述人工或CV流程依然可用。

## 3. 数据准备步骤

1. 固定A的源版本与几何处理顺序。若A经过稳像、裁切或旋转，mask必须用相同变换，不能直接复用旧版本像素。
2. 检查mask的白色含义；物体分割mask与“显示下一镜头的区域”可能相反，按揭示关系转换。
3. 把物体侧面、金属壳、运动模糊和薄边纳入设计；手动复核高对比边缘。
4. 羽化在mask准备阶段按像素与边缘实际清晰度设计。当前 `--feather` 只控制无mask时的线性擦除边宽，提供的mask保留自身灰度柔边。

## 4. 已有合成步骤

1. 预计算将被访问的mask索引，核对文件存在。
2. 当前执行器要求所用首mask平均白色占比不超过约2%、末mask不低于约98%，用于避免突然跳入/跳出；这是实现中的连接契约，不是实物分割准确率指标。
3. 读取mask，按A尺寸缩放，再应用与A相同的输出裁切矩阵。
4. 用 `C=A*(1-alpha)+B*alpha` 合成，过渡前后分别显示A/B。不会自动修复错时、mask身份或未纳入的物体侧边。

## 5. 失败恢复

- mask头尾不满足连接契约：调整真实过渡区间或追加设计允许的全黑/全白保持帧，不能跳过检查来掩盖错误时序。
- 边缘漂移：回到对应源帧核对取景、mask方向与索引；羽化不能替代配准。
- mask短缺或帧率不一致：按真实时间映射补足数据或缩短镜头，不复制未知边界并声称完成真实跟踪。
- 没有实物数据：可以交付线性擦除，但应说明是几何转场。

## 6. 验收与指标

**当前报告已有**：使用的mask索引、合成类别、白色语义，以及时间线和解码结果。

**需另行执行**：将mask边缘叠在原片上逐帧复核，统计与少量人工边界的距离/IoU、揭示比例曲线、接缝抖动与漏边区域。复杂真实遮挡的面积可以回退，不能机械要求所有mask单调增长。

正常速度看遮挡物进入、覆盖与离开，再慢看薄侧面和主体交叉。默认无声，跨场景声音需单独组织。
