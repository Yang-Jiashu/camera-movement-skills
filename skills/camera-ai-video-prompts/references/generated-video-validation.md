# 生成视频的CV检验设计

这是一份需要实际视频/CV工具执行的检验流程。本提示词技能不内置生成器、自动质量评分、稠密光流模型或语义身份识别；没有运行工具时只输出计划，不填写“已通过”。

## 输入契约

- 原始提示词、设计镜头、预期时长/画幅、参考首帧或参考片、实际生成视频，以及工具是否真正提供相机控制。
- 分开列出必须满足的动作与允许的创作变化；输入图没有记录的背面或遮挡区，不具有可验证的真实几何参考。
- 核查输出帧率/时间戳、方向、色彩标签与完整解码。VFR分析要按真实时间戳或先规范到明确CFR，不能直接用帧号当秒数。

## 分镜与运动检查

1. 正常播放整段，标记是否有非预期切镜、构图漂移、动作缺失或多余阶段。直方图跳变或帧差可辅助定位，不能单凭它们把甩镜、曝光变化判成失败。
2. 为静态背景选择ROI，使用角点LK正反向跟踪和RANSAC相似变换，观察表观平移、旋转和尺度随时间变化。
3. 同时标记主体位置与大小，分开判断主体运动和背景运动。高背景内点率不能证明主体身份或物理相机轨迹正确。
4. 需要密集运动观察时，可另行调用实际可用的稠密光流工具，检查流向、遮挡附近不一致和异常变形；稠密流本身不证明世界几何真实。

对于单幅平面或远景，仅凭全局二维变换通常不能可靠区分相机横摇、横移或变焦。需要前后景视差、遮挡关系、主体尺度及参考信息共同支持，保留不确定性。

## 按镜头目的复核

| 预期镜头 | 应观察的证据 |
| --- | --- |
| 静镜 | 背景刚性结构稳定，场景内动作仍按提示发生 |
| 跟拍 | 同一主体持续可见，相机相对位置与距离变化符合设计；不只是主体原地踏步 |
| 推近/拉远 | 主体尺度、透视或前后景关系按目标变化；区分表观整体缩放与有视点变化的运动 |
| Dolly zoom | 主体尺寸近似稳定，背景相对尺度发生变化，主体与建筑没有为满足效果被拉伸 |
| Roll | 刚性参照绕光轴改变方向，起止角度及回正符合设计 |
| 环绕/穿行 | 遮挡、新露出表面和空间连通性连续；单张参考不支持验证未知背面的真实外观 |

## 刚性、轮廓与连续性

- 建筑或产品可用稳定边缘/局部特征检查尺寸、直线和角点关系；不要把跟踪器漂移直接当成模型变形。
- 主体外观、服装、肢体、交叉和遮挡后再次出现要视觉复核；可选外部语义工具需要独立验证，不能由光流内点率推出身份一致。
- 对水、雾、反射等非刚性区域，避免套用静态建筑的约束。区分预期环境运动与结构融化。
- 无意的重复帧、时间回跳或突变可由逐帧差异和轨迹辅助定位；片尾静帧或设计停顿须按任务解释。

## 结果与迭代

报告实测帧数、检查区间、ROI、算法、发现与剩余不确定性；中心误差、尺度漂移、几何残差和流场统计的阈值按输出分辨率、主体大小和设计强度校准。

先修主要偏差：相机动作错误、主体动作错误、结构连续性或落点。每次优先调整一个关键因素，实际再生成/复查后更新结论；不能只改提示词就宣称生成视频已改善。
