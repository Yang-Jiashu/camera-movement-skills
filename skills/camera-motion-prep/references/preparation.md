# 视觉预处理规范

本页区分现成CLI与需要另行执行的流程。归一化坐标均针对解码后、方向正确的源画面，ROI顺序为 `x y width height`；`mask`种子为 `x y`。

## 1. 背景运动诊断：已实现

1. 选连续、无剪切的短片段，明确分析fps；`--analysis-width`仅控制特征估计分辨率，不代表输出分辨率。
2. 在 `--background-roi` 中选建筑、地面等稳定纹理；不提供时全画面估计，移动主体可能污染结果。
3. Shi–Tomasi选角点，金字塔LK追踪相邻分析帧，前后向检查剔除不一致匹配，再用RANSAC估计相似变换。
4. `--min-points`限制可靠匹配数量，`--min-inlier-ratio`限制几何一致性；`--fb-threshold`及`--ransac-threshold`以分析图像像素计。缩小分析尺寸时需重新校准，默认值不是身份或稳像质量保证。
5. 阅读逐帧报告：特征数量、内点比例、重投影误差和失败原因；检查失效帧的实际画面。高内点比仅说明当前匹配能被模型解释。
6. 若水面、前后景视差或主体运动主导，换ROI或分段；简单全局模型无法解释时保留原运动或改外部局部稳像。

## 2. 相似变换稳像：已实现

1. 先运行诊断。设置秒单位 `--smoothing` 和0–1强度 `--strength`，从轻度修正开始；有意横移仍应可读。
2. 累积帧间相似变换，平滑轨迹，再求从当前轨迹到平滑轨迹的校正。它是二维全局估计，不是相机三维位姿。
3. `--zoom`设基础裁切，默认全段统一增加裁切以覆盖有效像素，`--max-zoom`限制损失。不能覆盖则失败；不要用镜像边缘装作原场景。
4. 默认 `--fallback stop` 在估计不可信时停止。`hold`把失败帧对的增量设为单位变换，沿用此前累计位姿；后续可信帧对仍会继续更新。它不冻结视频，也不等于修复了失败区间的未知运动。报告会标记失败，连续失败应重新分段。
5. 输出画幅与稳像裁切一起计算；后续滚转、跟踪再吃余量时合并预算。当前独立准备工具会编码中间片，应选合适CRF并保留源文件，避免反复转码。
6. 输出静音。时间未变的CFR片段可以另行对应原声；如重采样、变速或VFR规范化，应核对时间映射后再混音。
7. 检查建筑直线是否晃动、画面是否追赶、主体是否被裁掉，以及失败/hold区间。报告的 `predicted_model_residual_after` 来自拟合轨迹和平滑轨迹的计算，不是对编码后画面重新跟踪所得的改善测量；若要报告实际稳像收益，应另行重跟踪输出并使用可比较的背景区域。滚动快门“果冻”、强视差和原始模糊不在该模型修复范围。

## 3. GrabCut静态掩码：已实现

1. 输入照片，或用 `--time`从视频取一帧。矩形必须完整包围前景，框外视作确定背景。
2. 在前景内部添加可重复的 `--foreground-point`，在误选背景添加 `--background-point`；两类种子均要根据实际画面设置。
3. 运行GrabCut并检查结果；颜色相似、反光或细线结构可能失败。增加迭代次数不能替代有效种子。
4. `--analysis-width`控制分割计算尺寸；alpha恢复到源尺寸，缩小分割可能丢失细节。`--feather`是最终源图像像素单位的高斯sigma，只为边缘过渡。
5. 输出8位灰度PNG：0背景、255前景，中间值为羽化过渡。结果是静态分割资产，不是分层完成、背景补全或透明材质真实抠像。
6. foreground与alpha必须同尺寸、同源坐标。background需要与它们空间配准，通常可保持同尺寸；当前分层CLI也接受不同尺寸背景，但调用者必须定义可比较的锚点与覆盖关系，工具不会自动配准。背景被移开后出现的空洞需另外处理。切换到遮挡转场时，alpha语义要转换：擦除mask白色表示下一镜头B显现，不能直接假定前景白色就正确。

## 4. 扩展与条件流程

- **视频分割**：可用SAM 2等交互视频模型，按镜头初始化并补正；导出逐帧mask、object ID、fps、起始时间和原尺寸。在遮挡、重现、运动模糊处重新核对目标。不得直接把二值分割当发丝matting。
- **透明边缘**：另用matting模型或人工trimap；保留float/高位深alpha母版，检查预乘与非预乘约定，最后再转换消费端格式。
- **深度**：单目模型用于相对层次；记录近远方向、单位和归一化。不同帧不能各自随意归一化导致深度跳变，需时序校准。没有标定时不能从相对深度宣称米制或真实视角。
- **稠密光流**：motion_masks已内置DIS/Farneback双向流、局部分割修正和质量检查。RAFT仍属可选外部模型；估计流场本身不等于完成插帧。
- **补全背景**：motion_layers已内置Telea/NS有限补洞和整段可见性预算，按approved_motion渲染。大孔、复杂结构或更大运动需真实无遮挡参考或可用修复工具。
- **真实环绕/三维移动**：需要有视差的多视图、相机标定/位姿和可用重建。平面变换、单张深度或分层位移只能提供有限近似。

整库安装可按需读 [共享CV流程](../../camera-movement-direction/references/cv-pipeline.md) 和 [组合配方](../../camera-movement-direction/references/cv-recipes.md)；缺少总控技能时，本页的输入、决策和限制仍可单独使用。
