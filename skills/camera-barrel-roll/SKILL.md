# 数字滚转

让画面绕光轴旋转，在起止构图之间保持有效边缘和可辨认落点。滚转改变地平线方向；它不会揭示物体侧面或背面。

## 输入与动作设计

- 输入8位SDR照片或视频，明确选段、输出画幅及角度起点和终点。
- 用户要明显展示时，使用能看清完整动作的幅度；不要把360度请求自动弱化为几度倾斜。
- 选择可辨认的地标、道路、屋顶或纵深线。快速旋转前后留可读的短暂停顿，并与声音或剪辑节拍配合。
- 360度终点应回到正向；180度终点会倒置，需要与用户的设计意图一致。

## 参数与执行

| 参数 | 决策 |
| --- | --- |
| `--angle-start` / `--angle-end` | 指定动态滚转角度，不混同静态Dutch angle |
| `--zoom-start` / `--zoom-end` | 请求的取景倍率，自动安全拟合可能增加实际倍率 |
| `--center-start` / `--center-end` | 源画面归一化中心；偏心旋转更容易耗尽边缘 |
| `--no-auto-fit` | 仅在已自行验证全程旋转几何时使用；默认保留安全拟合 |

例：完整转一圈并回正：

```bash
python3 scripts/apply_camera_motion.py roll --input input.mp4 --output roll.mp4 --duration 4 --angle-start 0 --angle-end 360 --zoom-start 1.1 --zoom-end 1.1 --easing smooth
```

先看 `roll --help` 再设置输出尺寸与取段。原始时间对应不变时可用 `--audio source` 保留原声；默认无声。HDR需先显式转换到SDR。

## 安全倍率与清晰度

16:9矩形绕中心完整旋转、保持满幅时，安全倍率峰值约为 `sqrt(1+(16/9)^2)=2.04`。这只是同画幅居中旋转的几何值；偏心中心、稳像和其他变换需要额外余量。

查看程序报告的实际拟合倍率和采样放大。高倍率导致源像素不足时，可降低输出分辨率、缩小角度或接受短暂的采样放大，并如实记录。

不要通过大面积边缘复制或黑边掩饰覆盖不足。运动模糊若用于表现速度，应随速度变化；检查多重轮廓和地标重影。叠加文字通常保持稳定，避免旋转后不可读。

## 验收与交付

正常播放完整动作，逐帧检查四角最接近边界的角度，以及加速、回正和落点。首尾没有黑边不能证明中间旋转安全。

报告请求角度、实际倍率、拟合与中心修正、采样放大情况。称“数字滚转/后期barrel roll”，不把二维旋转写成真实orbit或FPV飞行轨迹。

## 运行入口

视频入口按CFR帧索引处理，VFR不会自动检测；精确时序或原声同步前核查帧率，必要时先规范为明确的CFR。

整库共用运行时。仓库根目录使用 `scripts/apply_camera_motion.py roll`；安装后的本技能 `scripts/run.py` 已固定 `roll`，无需再次追加子命令。先读 `--help`；只有技能目录时不能假设共享代码已安装。
