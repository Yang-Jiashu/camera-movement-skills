# 滚转的CV处理设计

此流程处理二维画面滚转；不估计物体侧面或构建真实orbit。效果命令已有的是确定性仿射几何与逐帧覆盖检查，稳像、主体检测或运动模糊分析需另行执行。

## 1. 输入契约

- 8位SDR图像或CFR视频，明确起止角度、起止中心、请求倍率、输出画幅与时长。
- 起止角度与回正意图一致；360度回到相同方向，180度通常保持倒置。
- 源画面需有足够分辨率和边缘支持。透明背景、非矩形拼接有效区不能被当作完整实拍矩形使用。

## 2. 预处理设计

1. 查看原片是否已有roll、手抖或有意pan，避免后期旋转与原运动互相抵消。
2. 若需先稳像，用静态背景估计并保留低频有意运动；把稳像变换与滚转裁切合并计算，或准确传递处理后的有效边界。
3. 选择能辨认方向和回正的地标/地平线。主体偏心时核查旋转中心，不用自动显著性推断替代用户的明确指定。

同库的预处理技能可辅助分析与稳像；缺失时按上述流程用可用CV工具核查。本roll命令不会自动完成这些步骤。

## 3. 已有几何算法

1. `rotation_fit_zoom`根据源/输出尺寸、角度和中心，计算保持输出矩形在源内所需倍率。
2. 默认对请求的全部角度和中心路径预计算安全值，使用整段统一的安全倍率下限；当前实现不是自动制作“先推近、转圈、再拉出”的三阶段摄影动作。
3. 每帧将请求倍率与安全下限取较大值；中心、角度和倍率按所选插值变化。
4. `crop_matrix`计算输出到源图的逆仿射，检查四角覆盖，`warpAffine`以三次插值采样。
5. `--no-auto-fit`仅关闭安全倍率预计算，后续越界检查仍生效；它不是允许黑边的开关。

16:9、同画幅居中完整旋转的理论倍率峰值约2.04。任意偏心中心、原图画幅、稳像余量或非矩形有效区应重新计算，不直接复制这个数值。

## 4. 速度与模糊设计

- 当前命令可平滑或线性插值角度，不内置基于快门曝光的物理运动模糊。
- 需要更复杂节奏时，用明确的分段关键帧或组合操作，并保持采样支持；不要声称单条简单命令已实现任意曲线。
- 如另行做多曝光采样或后期方向模糊，应检查重复轮廓和文字重影，并在高速段后恢复可读落点。稠密光流并非执行纯滚转所必需。

## 5. 失败恢复

- 安全拟合导致放大太多：降低输出尺寸、减小角度、调整中心或使用更高分辨率源；按画质目标设置放大上限。
- 不能保持偏心中心：调整中心或改变构图，不用边缘复制伪造新像素。
- 原片抖动加旋转难读：减轻旋转速度，先验证稳像，或换场景；更大模糊不一定更好。

## 6. 验收与指标

**当前报告已有**：整段安全倍率下限、逐次采样汇总的最小边界余量、clamp数量、最大采样放大，以及全量解码/帧数/fps/尺寸。

**另行观察或测量**：累计roll角度、起止方向误差、角速度与加速度、最紧边缘角度、地标局部锐度、叠字可读性。几何覆盖合格不代表旋转节奏或清晰度合格。

正常速度看完整转动，再慢看转速变化和回正；数值目标按动作强度与展示目的设定，不把某个速度阈值视为普遍标准。
