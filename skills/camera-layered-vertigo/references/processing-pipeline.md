# 分层眩晕的CV处理设计

高层camera_pipeline layered-vertigo现可从原图ROI/种子或alpha执行分层、有限补洞、整段运动预算并渲染；下文低层合成契约仍适用于已经准备好的图层。QA不合格时先修初始化或减小动作，不把算法运行成功当作语义完成。
效果命令只执行显式两层的刚性尺度/位移与alpha合成。分割、单目深度和背景补洞都需要调用者准备，不能由成功导出推断这些步骤已完成。

## 1. 输入契约

- 8位SDR前景RGB、背景RGB及与前景等尺寸的灰度alpha；白色保留前景、黑色显示背景。
- 层资产表示同一取景和空间关系，前景中主体需要维持刚性；非预乘颜色与alpha分别输入。
- 需要锚点、每层起止相对倍率、位移和时长。倍率1表示按比例覆盖输出，不是源像素仿射scale的绝对值。

## 2. 资产准备与算法选择

以下为**需另行执行**的流程：

1. 人工多边形、颜色/边缘辅助或GrabCut可分离轮廓明确的建筑；复杂人体、毛发和透明物可使用外部分割/抠像工具。
2. 单目深度可帮助辨认前后层，但不提供可靠米制尺度或隐藏背面；实际alpha仍应沿真实物体轮廓修正。
3. 为被前景挡住的背景补洞。小范围纹理可用传统图像修补；大区域需要真实参考视图、补绘或明确的生成方法，并记录范围。
4. 把与主体连在一起的平台、屋顶或地面纳入合适层，避免主体像卡片一样脱离其支撑物。

只有图像路径不足以证明这些资产质量；先查看轮廓叠加和补洞区。可选模型需要实际可用工具，不属于现有效果命令的自动能力。

## 3. 预览与构图设计

- 用首、中、末尺度静态预览，找出背景收缩后最易露出的接缝与未知区。
- 选择有远景结构的素材；纯天空或均匀水面的缩放可能几乎没有眩晕观感。
- 令前景起止倍率与位移一致，固定近处主体；给背景有限反向尺度变化。效果强度由实际层次和mask支持决定，不依赖某个通用百分比。

## 4. 已有合成算法

1. 以源图覆盖输出的基础比例乘相对倍率，构造每层正向仿射矩阵。
2. 以共同归一化锚点定位两层，并用归一化输出位移叠加平移。
3. 对背景输出四角求逆映射；覆盖不足报错，或在显式clamp下调整位移。前景可以只覆盖局部，因为其外侧由alpha透出背景。
4. 前景RGB和alpha使用同一几何变换；RGB三次插值、alpha线性插值，然后做直alpha混合。
5. 记录前后景倍率范围和背景最小边界余量；不根据深度图逐像素弯曲建筑。

## 5. 失败恢复

- 出现矩形水面块或重复纹理：回到mask和补洞检查，不只增加羽化。
- 主体边缘光晕：确认alpha与前景配准、RGB边缘是否含背景污染，按实际尺度修边。
- 主体脱离地面：重新分层或扩大刚性支撑区域，而非用不规则形变硬拉回来。
- 背景露空：减小尺度变化/位移、增加实际背景覆盖，或改变输出；不能把复制边缘称为真实新空间。

## 6. 验收与指标

**当前报告已有**：两层倍率范围、背景最小余量、合成方法及全量解码/帧数/fps/尺寸。

**需另行测量**：前景特征首尾尺度变化、主体内部直线/边缘刚性、轮廓偏差、补洞接缝可见性、相对背景变化是否可读。可用前景稳定角点加鲁棒相似变换估计尺度，但高内点率不能证明背景真实。

正常播放后慢看分层边缘；记录补洞方式与幅度限制。交付明确为2.5D分层眩晕，不能宣称真实dolly zoom、完整3D或恢复了未拍到的物体背面。
