# 八个场景的镜头配方

下面的时间、倍率与角度都是设计起点，按主体、场地和素材调整。执行前先查看画面与元数据；设计值不能直接写成已验证结果。每个配方都给出实拍、已有素材和 AI 的选择条件，方便把一个观看目的转成可实现的镜头。

## 1. 建筑：从街道揭示楼顶

**目的**：让观众先感到人的尺度，再看到建筑高度。

- **起始→结束构图**：台阶、门口或街道细节 → 能辨认屋顶与整体比例的构图。
- **动作与节奏**：约 6 秒，开头短停，随后缓慢向上俯仰摇，终点停稳。机位位置基本不动；若要真正越过矮墙，则另设计升降路线。
- **实拍条件**：起止视野都能拍到，转向中建筑与前景关系清楚；对焦覆盖需要阅读的范围。
- **已有素材**：原片已有俯仰时优先选取完整动作。单张高分辨率照片可做纵向裁切窗口移动，准确称为数字重构图；先确认屋顶和建筑边缘都有有效像素。
- **AI 方向**：相机保持在街道同一位置，从入口缓慢转向屋顶；建筑刚性，结束在可读的屋顶构图。若模型仅放大画面，说明需要的是转向而非变焦。
- **验收**：起点确实建立尺度，终点确实增加信息；建筑没有弯曲或中途被意外切断，速度连续，地平线变化符合俯仰动作。

## 2. 街巷：跟随人物进入空间

**目的**：让观众随人物走进一个有纵深的地点。

- **起始→结束构图**：人物背面中景、巷口两侧可见 → 人物到达街内落点，店面或门洞展开。
- **动作与节奏**：约 8 秒，相机从后方与人物同步前进，保持大致距离；如果前景门框经过，先把“经过门框”与“最后看到什么”安排好。
- **实拍条件**：机位路线与人物路线配合，人物不被前景长时间挡住，步行速度与镜头时长匹配。
- **已有素材**：保留已有跟拍的真实前进感；必要时用主体跟踪维持人物位置。若原片只有固定机位或单张照片，不能靠放大补出巷内的新视角。
- **AI 方向**：人物向巷内走，相机从后方同速前移；两侧店面自然经过，人物距离和背面身份保持连续。
- **验收**：人物确实行走，相机和主体运动可区分；前后景遮挡自然，人物没有滑行、改变身份或突然跳向另一侧。

## 3. 人物：侧跟并保持行动空间

**目的**：关注人物的表情和行进，让观众看清动作而不追着画面找人。

- **起始→结束构图**：人物位于画面一侧，面前有适量空间 → 行进方向与主体占比延续，结束在完整动作后的落点。
- **动作与节奏**：约 5 秒侧跟；人物与机位大致平行移动。若仅做后期跟踪，将裁切窗口平滑跟随人物，保留视线方向的空间。
- **实拍条件**：说明机位在哪一侧、相对距离和行进速度；背景要能帮助读出人物在移动。
- **已有素材**：指定人物初始区域，检查遮挡与画幅余量。跟踪置信不足时停止自动路径或采用明确的回退，不能在人物被挡住后任意追到背景上。
- **AI 方向**：人物向右走，相机在其左侧平行前进，保持中景与大致距离；背景经过，脸部与步态连续。
- **验收**：检查整个人物范围而非只看跟踪中心；头、手和脚不被无意裁断，窗口没有追踪跳动，背景运动符合主体行进。

## 4. 美食：沿前景揭示主菜

**目的**：先看到一个质感细节，再把注意力交给完整食物。

- **起始→结束构图**：杯沿、餐具或近处配料占一侧 → 主菜成为画面明确主体，关键食物保持完整。
- **动作与节奏**：约 4 秒小幅横移，前景经过后停稳；也可用短慢推强调食物表面。
- **实拍条件**：前景与食物有距离差；移动范围、对焦和景深能同时服务于揭示过程。
- **已有素材**：已有横移可保留视差；固定机位可做数字窗口移动。原片没有记录蒸汽、拉丝或切开动作时，不把后期缩放描述成这些动作发生过。
- **AI 方向**：静止餐盘，机位缓慢横移经过前景杯沿，完整主菜逐渐显露；需要蒸汽或食物动作时单独描述，并检查食物形态。
- **验收**：前景经过有揭示价值，主菜没有形变；焦点交接明确，盘沿与食物不被意外切断，结尾足够清楚可辨认。

## 5. 水景：让真实水流承担运动

**目的**：展示水的连续性和环境尺度，给高强度片段之间留出呼吸。

- **起始→结束构图**：水流局部或较紧的环境构图 → 稍宽的水景与周边建筑、人物比例。
- **动作与节奏**：约 7 秒，采用静镜或缓慢拉远；静镜时镜头不动，运动来自水、雾和现场人物。
- **实拍条件**：保留水流的连续时段，选择不会持续遮住主要水景的观察位置。
- **已有素材**：用原片水流和自然声。数字拉远只能退到原片已记录的范围；照片中的水若做局部动画，应明确标为合成。
- **AI 方向**：相机固定，水持续下落，建筑与构图稳定；若要拉远，再明确相机后退、环境范围逐渐展开。
- **验收**：水流连贯，建筑不随水变形；静镜无不合意漂移，真实原声与可见运动对应，结尾没有被裁切窗口推到无效区域。

## 6. 产品：用弧线展示体积

**目的**：让观众理解产品正面、侧面和材料，而不是只看见平面图片变大。

- **起始→结束构图**：产品正面略偏一侧 → 显示约一个小弧段后的侧面信息，主体尺寸大致稳定。
- **动作与节奏**：约 5 秒，机位围绕静止产品走一段弧线。转台方案则让产品自身转动，交付时分别标明实现方式。
- **实拍条件**：有相应侧面可拍，产品与背景分离，反射面、焦点和光线变化可控。
- **已有素材**：优先使用原始弧线、转台或多视角素材。只有单张图片时可做小幅分层视差或数字重构图，无法验证未拍到的接口、背面和结构。
- **AI 方向**：机位沿指定方向绕静止产品移动一个小弧段，产品几何与标识一致；新露出侧面由模型推断，精确产品展示应补参考视图或三维资产。
- **验收**：产品尺寸与轮廓稳定，侧面变化符合运动，反射不突然跳变；型号、标识和部件没有被重画成不同产品。

## 7. 旅行开场：空间、行进、地点三步建立

**目的**：用约 12 秒让观众知道在哪里、正在怎么走、接下来进入什么场景。

| 设计时段 | 起始→结束构图 | 动作与作用 |
| --- | --- | --- |
| 0–4 秒 | 高处或宽景建立地理 → 清楚的地点落点 | 根据风格选择静观、推进或数字滚转；滚转前后保留可读构图 |
| 4–8 秒 | 街道行进 → 新街景或湾岸 | 甩镜连接同方向运动，快段经过切点，随后恢复清楚画面 |
| 8–12 秒 | 前景柱子、门框经过 → 进入下一地点 | 使用真实遮挡边缘或明确的合成过渡，结束在能辨认地点的镜头 |

- **实拍条件**：分别规划三段所需视角和落点，拍下转向、遮挡过程与停稳段，给剪辑留选择余量。
- **已有素材**：先依据原片实际运动决定镜头顺序。高分辨率画面可做数字滚转；遮挡掩码必须对应当前源片、起始帧和分辨率，不能直接套用另一版本。
- **AI 方向**：逐镜头描述地理信息、机位路线和新地点；若需要连续穿行，说明空间如何连接，并检查衔接是否真能成立。
- **验收**：每段都有可读落点，整体方向有意且可理解；音乐重拍和风切服务于切点，避免全程模糊或所有镜头都重复同一推近。

## 8. 结尾：拉远、停稳、让环境留住人物

**目的**：从一个细节退出，给情绪和声音留出结束时间。

- **起始→结束构图**：人物或旅途细节较紧 → 人物留在较大的环境里，或主体退出后留下完整场景。
- **动作与节奏**：约 6 秒慢拉远，最后短停；如果原片没有拉远，可用静镜和主体自然离场完成相同观看目的。
- **实拍条件**：终点有值得保留的环境信息，主体离场或停留的位置与镜头作用一致。
- **已有素材**：可在有效画幅内数字拉远，但不能退到原片边界之外。需要结尾定格时明确它是有意设计，声音也应获得收束时间。
- **AI 方向**：相机缓慢后退，人物停留或继续沿既定路线离开，环境范围逐渐扩大，最后稳定构图。
- **验收**：结尾确实增加环境信息，主体仍可理解；速度自然收束，画面没有撞到边界，声音和标题不会在未完成的动作中突然截断。

## 交给执行 skill 时带上什么

```text
素材路径或镜头描述；输出画幅与时长；主体/锚点或初始区域；
起止构图与运动方向；是否允许图层合成或生成新内容；需要保留的声音。
```
